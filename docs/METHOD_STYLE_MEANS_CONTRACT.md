# METHOD STYLE MEANS CONTRACT

The layer enforces separation:

- Method may produce thought.
- Style operates only inside a declared method.
- Means serves style only.
- Means cannot issue judgment.
- LLM output is means, not evidence and not judgment.
- Fluency is not proof.
- Tool output is not certificate.
- Scientific method alone cannot issue worldview/moral/legal/shari normative judgment.
- Normative judgment requires a normative evidence path.

This keeps evidence governance separate from generation fluency.
