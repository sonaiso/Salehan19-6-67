# Mustadil Pipeline

Mustadil Pipeline is the governed reasoner/verifier flow from reality grounding to epistemic audit.

## Purpose

Execute ordered verification without silent level skips.

## High-Level Flow

```text
Reality grounding -> semantic-relational structuring -> bayani-linguistic analysis -> usuli application -> epistemic audit
```

## Non-Negotiable Constraints

- no silent level skip
- no application before required preconditions
- no certificate without full gate completion
- no residual erasure
