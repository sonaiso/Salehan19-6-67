# Formal Monotonicity Draft

## Statement (Draft)

Given a fixed claim type and fixed governance constraints, if valid evidence increases
without adding new blocking residuals, transition legitimacy should not decrease.

## Informal Form

If \(E_1 \subseteq E_2\), all elements in \(E_2 \setminus E_1\) are valid, and
governance gates remain satisfied, then:

\[
L(T \mid E_2) \ge L(T \mid E_1)
\]

## Boundary Conditions

- No rank violation introduced.
- No contradiction introduced.
- No forbidden transition introduced.
- No governance gate regression.
