## MiniJudgmentKernel

Every layer transition must expose the same invariant kernel:

1. Input
2. Candidate
3. Constraint
4. Evidence
5. Residual
6. Ranking
7. Decision
8. ReverseTrace

## FractalLayer and LayerMaterial

Each `FractalLayer` declares `LayerMaterial` plus:

- material
- allowed inputs
- candidate types
- constraints
- evidence types
- residual types
- ranking rule
- decision rule
- reverse trace requirements

## GateContract

Certificate is blocked unless all hold:

- EvidenceObject exists and is valid
- ReverseTraceGraph is complete
- No blocking residual
- Governance gate is satisfied
- ProofObject exists

## Objects

### EvidenceObject

Must include source, strength, and independence metadata.

### ResidualObject

Must include type, severity, and propagation metadata.

### ReverseTraceGraph

Must include nodes, edges, and path completeness.

## LayerTransition

Each transition returns `GateResult` with full MiniJudgmentKernel fields.

## Certificate Conditions

Universal CFK CERTIFICATE requires:

1. Complete layer registry + validated transitions
2. Structural recurrence tests passing
3. Certificate gates passing in all required paths
4. Residual propagation preserved
5. ReverseTrace complete
6. ProofObject present
7. GovernanceGate passed

If any requirement is missing, theorem status downgrades to:

- INCOMPLETE, or
- HYPOTHESIS, or
- STRONG_HYPOTHESIS, or
- CERTIFICATE_CANDIDATE

This repository currently remains at **STRONG_HYPOTHESIS** for the full theorem.
