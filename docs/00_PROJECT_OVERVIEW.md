# Project Overview

Bayani / AFJG is a governed knowledge-verification and coding-judgment system.

It converts Arabic claims, model outputs, and pull-request artifacts into governed judgments:

- ZERO
- HYPOTHESIS
- CERTIFICATE

## Canonical Identity

- **AFJG:** Supreme governing law for judgment architecture and forbidden transitions.
- **Bayani:** Arabic epistemic verification layer.
- **MCD:** Implementation namespace (`src/mcd`) with runtime modules, CLI, and tests.
- **Coding Copilot Auditor:** Industrial dogfood product for governed PR auditing.

## Scope

This repository includes:

- machine-readable specification and schema
- partial runtime implementation
- governance and judgment logic
- verification and regression tests

This repository does **not** claim completion of all planned products.
