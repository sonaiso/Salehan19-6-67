# 01 — Mind Validity Standard

Final epistemic judgments are restricted to:
- ZERO
- HYPOTHESIS
- CERTIFICATE

Constraints:
- No fourth final state.
- No certainty rise without valid evidence.
- Analysis output alone is never proof.
- No certificate without ProofObject + GovernanceGate + ReverseTrace.
- Certainty is a governed epistemic ceiling derived from transition completeness, residual state, and trace completeness.
- If reconstruction of legitimacy is incomplete, downgrade to HYPOTHESIS or ZERO.
