# GOVERNED USER INTENT

The system must govern intent before answer judgment.

Intent governance covers:
- raw request,
- normalized request,
- inferred intent,
- intent status (explicit/inferred/ambiguous/missing),
- uncertainty preservation,
- residuals and trace references.

If intent is missing, certificate is blocked.
If intent is ambiguous/inferred, uncertainty must be preserved.
Ambiguous intent with preserved uncertainty can remain hypothesis.
