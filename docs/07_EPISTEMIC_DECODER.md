# Epistemic Decoder

The Epistemic Decoder governs transition from language output to verified epistemic decision.

## Purpose

Constrain decoder behavior so generated answers do not bypass evidence and governance.

## Core Path

```text
Reality/Text -> Distinction -> Mapping -> Evidence -> Certainty Control -> Judgment
```

## Governance Notes

- Linguistic fluency is not evidence by itself.
- No certainty rise without matching evidence.
- Reverse trace must remain available for audit.
