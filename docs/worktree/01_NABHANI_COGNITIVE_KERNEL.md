# 01 — Nabhani Cognitive Kernel (Worktree)

## Root Correction

Zero is not only a final prohibitive judgment.
Zero is also the first cognitive alert:
conscious detection that the sensed object is not yet sufficiently known.

## Zero Types

1. **Epistemic Zero Genesis**
   - initial alert to epistemic absence
   - starts inquiry and concept formation
2. **Final ZERO**
   - final blocking judgment after proof/trace/morphism/evidence failure
   - blocks certification

## Brain and Mind Distinction

- Fit Brain is a biological condition, not the mind itself.
- Mind is not the fit brain.
- Mind is the governed linking operation between sensed reality and prior information.

Governing statement:

- Brain is a condition.
- Mind is an operation.
- Judgment is a governed output.
