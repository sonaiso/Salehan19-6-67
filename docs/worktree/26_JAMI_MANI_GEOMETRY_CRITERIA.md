# 26 — Jami/Mani Geometry Criteria

## Jami (Comprehensive) Criteria

The geometry is jami when every epistemic unit can be represented by:

- node identity and type
- gate state and score state
- dimensions
- domain
- relations and morphic edges
- residuals
- trace references
- judgment boundary

## Mani (Preventive) Criteria

The geometry is mani when it blocks:

- root/pattern/derivative/irab promotion as factual proof
- metaphor-as-literal-certificate
- model/tool output as evidence or certificate without governance
- certificate without ProofObject
- certificate without GovernanceGate
- certificate without ReverseTrace
- residual erasure
- silent level skip

## Acceptance Boundary

Phase 2.1D is accepted when:

- node/edge/dimension/domain/relation models are formally separated
- gate and score separation is executable and tested
- folding cannot hide blocking residuals
- retrieval requires trace
- final judgments remain: ZERO / HYPOTHESIS / CERTIFICATE
