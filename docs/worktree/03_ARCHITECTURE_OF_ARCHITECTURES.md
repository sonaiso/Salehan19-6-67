## 1) Mind Geometry

- **purpose:** generate governed cognitive distinctions before language

- **outputs:** distinction, identity, concept primitives
- **invariants:** mind precedes language; no certainty rise without evidence
- **forbidden transitions:** `silent_level_skip`, `residual_erasure`
- **residuals:** `mind_geometry_not_runtime_complete`
- **current repository status:** HYPOTHESIS
- **next required work:** runtime contracts for distinction/identity/concept

## 2) Language Geometry

- **purpose:** reveal mind state through signifier/signified structures
- **inputs:** lexical units and contextual constraints
- **outputs:** governed signification pathways
- **invariants:** language reveals mind, does not self-certify truth
- **forbidden transitions:** `root_or_pattern_as_factual_proof`, `derivative_as_proof`
- **residuals:** `language_geometry_fragmented`, `signifier_signified_not_fully_bound`

## 3) Judgment Geometry

- **purpose:** map governed states to ZERO/HYPOTHESIS/CERTIFICATE

- **invariants:** no certificate without ProofObject, GovernanceGate, ReverseTrace
- **forbidden transitions:** `certificate_without_proof_object`, `certificate_without_governance_gate`, `certificate_without_reverse_trace`
- **residuals:** `concept_judgment_evidence_bridge_partial`

## 4) Evidence Geometry

- **residuals:** `bayani_runtime_mixed_with_spec`
- **current repository status:** PARTIAL_RUNTIME
