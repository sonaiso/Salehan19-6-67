# Formal Transition Algebra

## Transition

For a transition \(T\) from state \(A\) to state \(B\):

\[
T: A \rightarrow B
\]

## Legitimacy Predicate

\[
L(T)=1 \iff C(T)\land R(T)\land E(T)\land G(T)
\]

Where:

- \(C(T)\): Context validity
- \(R(T)\): Rank validity
- \(E(T)\): Evidence validity
- \(G(T)\): Governance legitimacy

## Operational Reading

A transition is legitimate only when all four dimensions are valid at the same time.
If any dimension fails, legitimacy collapses to \(L(T)=0\), and the transition cannot
raise certainty to certificate level.
