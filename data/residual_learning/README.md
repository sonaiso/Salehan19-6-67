# Residual Learning Data — Phase 7

This directory contains data for the **Cognitive Residual Learning Engine**.

## Files

| File | Description |
|------|-------------|
| `mock_gpt_proposals_ar.jsonl` | 100 mock GPT proposals (Arabic). No real GPT calls. |
| `mock_gpt_bad_outputs_ar.jsonl` | Subset of problematic proposals (all non-correct categories). |
| `residual_learning_cases_ar.jsonl` | Computed residual cases from mock proposals. |
| `residual_adversarial_candidates_ar.jsonl` | Adversarial candidates (blocking + high severity residuals). |
| `generated_adversarial.jsonl` | Generated by `residual-build-dataset --target adversarial`. |
| `generated_test_specs.jsonl` | Generated by `residual-test-specs`. |

## Mock Proposal Categories

1. `correct_with_evidence` — valid proposals with evidence
2. `answer_without_source` — answers lacking source citations
3. `false_certainty` — near-certainty claims without evidence
4. `harm_equals_haram` — confusing harm (ضرر) with haram (حرام)
5. `api_as_authority` — treating GPT/API output as primary evidence
6. `metaphor_as_literal` — treating metaphors literally
7. `analogy_without_illah` — analogies lacking proper reasoning basis
8. `prompt_injection_followed` — following injection instructions
9. `unsupported_generalization` — broad claims without evidence
10. `wrong_domain` — applying concepts across incompatible domains
11. `stale_source_as_current` — using outdated sources as current
12. `conflict_ignored` — ignoring expert disagreements

## Governing Formula

```
CognitiveResidual = GPTProposal − MathematicalContract
```

- **GPT suggests** → ProposalGraph
- **Mathematical Contract judges** → violations → residual types
- **Cognitive Residual teaches** → learning actions

## Quality Rules

- GPT output is **never** evidence
- GPT output **cannot** increase certainty
- All residuals are learning signals, not final truths
- Blocking residuals require human review
- No real GPT calls in tests
- No network calls
