# Foldable Learning Data — Phase 7.2

This directory contains data files for the Foldable Cognitive Residual Learning system.

## Files

### `mock_gpt_proposals_ar.jsonl`
100 mock GPT proposals in Arabic. 16 categories covering all major residual types.
Used as test input for the full foldable residual pipeline.
**No real GPT API calls are made — all proposals are deterministic.**

### `residual_patterns_ar.jsonl`
20 mined residual patterns with proposed invariants and tests.
Generated by `MathematicalPatternMiner` from batches of `CognitiveResidual` objects.

### `fold_signatures_ar.jsonl`
15 fold family signatures (one per fold type) exported from `FoldSignatureRegistry`.
Used for seeding `PatternMemory` and consistency checks.

### `pattern_memory_seed_ar.jsonl`
15 seed memory entries used to pre-populate `PatternMemory` at startup.
Each entry links a fold family to an example and counterexample.

### `fold_unfold_tests_ar.jsonl`
20 fold-unfold test cases verifying that the fold→unfold pipeline is consistent.
Each test specifies expected residual type, severity, and learning action.

## Formula

```
GPT Proposal − Mathematical Contract = Cognitive Residual
Cognitive Residual → Fold Signature → Pattern Memory → Recall → Learning Action
```

## Rules
- NO real GPT API calls
- NO network calls
- GPT output is NEVER accepted as evidence
- All calculations are pure Python, in-memory
